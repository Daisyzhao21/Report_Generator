# 🤖 AI 智能日报生成器

一个基于 Streamlit 的智能日报/周报生成工具，手机电脑都能用。

## ✨ 在线使用

点击链接即可使用（无需安装任何软件）：
**[https://你的应用名.streamlit.app](https://你的应用名.streamlit.app)**

## 🎯 功能特点

- 📱 **响应式设计**：手机、平板、电脑完美适配
- 🎯 **智能分类**：自动识别工作内容并分类
- 📊 **支持日报/周报**：一键切换报告类型
- 💾 **导出功能**：下载 Markdown 格式报告
- 🔒 **隐私安全**：数据不上传，完全在浏览器处理

## 📝 使用示例

**输入：**
```
修复登录bug，开会讨论需求，写技术文档，明天准备发布
```

**输出：**
- 今日完成：修复登录bug、开会讨论需求、写技术文档
- 明日计划：准备发布

## 🛠️ 本地运行

```bash
git clone https://github.com/你的用户名/DailyReportGenerator.git
cd DailyReportGenerator
pip install -r requirements.txt
streamlit run app.py
```
